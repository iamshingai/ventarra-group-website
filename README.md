# Ventarra Group website — first version

This is a small, responsive website made with plain HTML, CSS and JavaScript. It needs no paid software or build tools.

## View it on your computer

Open `index.html` in a web browser. The menu, section links and email link work without a server.

## Make it yours before sharing

1. Open `index.html` in a text editor such as Notepad or VS Code.
2. Search for `hello@ventarragroup.com` and replace it with the email address you want visitors to use.
3. Review the description of both divisions and adjust the wording to match the real services and plans. The current text is deliberately broad because detailed offerings were not in the project notes.
4. Change the page title and description near the top if the public company name or positioning changes.
5. Save the file and refresh the browser to see your edits. Change colours and layout in `styles.css`; the small-screen menu is in `script.js`.

## Publish when ready

These files can be uploaded to a free static website host. Before publishing, choose a real contact email, verify the company wording and check the site on a phone. You can add a domain later; it is not required to start learning or preview the site.
